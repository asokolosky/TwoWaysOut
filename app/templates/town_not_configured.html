Dashboard isn't configured

The town & city dashboard stays closed until it has a password and a session secret. It never opens without a password.

Set it up

  1. Copy .env.example to .env if you haven't already.
  2. Set DASHBOARD_PASSWORD to a shared password for town or city staff.
  3. Set SESSION_SECRET to a random string of at least 32 characters. Generate one with python -c "import secrets; print(secrets.token_urlsafe(48))"
  4. Restart the server.
